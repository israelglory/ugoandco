# UGO N & Co. Website Handoff

Everything needed to implement the approved website design.

## Start here

1. Unzip this folder into an empty project folder and rename it `handoff/`.
2. Open the project in Claude Code and paste the prompt from `PROMPT.md`.
3. To see the design yourself, open `design/preview/index.html` in a browser (all pages link to each other, and the mobile menu and inquiry pills work).

## Contents

```
PROMPT.md              Implementation prompt for Claude
DESIGN_SPEC.md         Colors, type, layout, components, page structure, motion
content/
  content.md           All website copy (clean Markdown)
  UGO_N_content.docx   Original copy document
design/
  screenshots/         Full-page renders: <page>-desktop.png (1440px), <page>-mobile.png (390px)
  preview/             Static HTML of every page
  source/              Original design canvas files (.dc.html), reference only
assets/
  logo-full.png        Original logo
  monogram.png         Transparent monogram for light backgrounds
  monogram-light.png   Monogram for dark backgrounds
  fonts/               Cormorant Garamond + Jost (woff2, SIL OFL) and fonts.css
```
